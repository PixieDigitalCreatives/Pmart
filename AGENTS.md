# Documentation Synchronization Rules

## Permanent Project Instruction: Mandatory Documentation Synchronization

Every PMart code change, bug fix, refactor, configuration change, schema/API change, or new feature must update all materially affected documentation and tests in the same task. Documentation synchronization is mandatory. 

When updating the UI, design, architecture, or components:
1. Update every affected UI/design document.
2. Update the architecture documents.
3. Update handover documents.
4. Verify claims against actual evidence.
5. Maintain the feature and remaining-work matrices.
6. Never mark untested behavior as verified.
